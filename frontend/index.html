缺少 SDPC 解码组件

浏览 .sdpc 切片需要厂商闭源解码库 DecodeSdpcDll.dll。出于许可考虑，本软件不随包分发该 DLL；安装开源 Python 包装后即可自动探测：

pip install sdpc-for-python

应用会依次探测：随包目录 → 环境变量 SDPC_DLL_DIR → Python site-packages 中的 sdpc/WINDOWS/dll。安装后重新打开切片即可；其余 19 个工具与台账功能不受影响。普通图片（png/jpg/tif）裁剪无需该组件。

本地优先 · 无遥测 · 数据只存在你的电脑上

台账、统计与图像工具都在本地运行，不上传任何数据。所有计算结果仅供科研使用，不用于临床诊断。
